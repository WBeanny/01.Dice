# 骰塔｜桌遊擲骰子模擬器

「骰塔」是一個可直接在瀏覽器使用的桌遊擲骰工具，支援標準六面骰、自訂骰子、數字／圖案骰面、一次擲多顆骰子，以及不同骰子設定的混合擲骰。

正式網站：<https://wbeanny.github.io/01.Dice/>

## 主要功能

- **標準骰**：內建 6 面骰，預設為 1～6。
- **一次擲多顆**：一般模式可設定 1～12 顆骰子同時擲出。
- **自訂骰子**：可建立 2～20 面骰，設定骰子名稱與每一面的內容。
- **數字／圖案骰面**：每一面可使用數字，或從內建 20 種常用圖示中選擇圖案。
- **混合骰子模式**：可同時選擇至少 2 種骰子設定，每種設定可選 1～6 顆一起擲出。
- **結果統計**：數字骰會顯示點數合計；圖案骰會統計各圖案出現次數。
- **設定保存**：自訂骰子、目前骰子與數量等設定會儲存在目前瀏覽器的 `localStorage`。
- **PWA**：支援漸進式網頁應用程式（PWA）；若瀏覽器提供安裝功能，可將網站安裝成獨立應用程式使用。
- **桌面／行動版介面**：採響應式版面，可在電腦與行動裝置瀏覽器操作。

## 基本操作

### 1. 一般擲骰

1. 在畫面下方選擇要使用的骰子設定，例如「標準骰」。
2. 使用右側的 `－ / ＋` 調整同時擲出的骰子數量；一般模式支援 **1～12 顆**。
3. 按下畫面中的 **「擲骰子」**。
4. 動畫結束後會顯示每顆骰子的結果；若骰面為數字，畫面會另外顯示點數合計。

### 2. 新增自訂骰子

1. 在下方骰子選擇列按 **「新增」**。
2. 輸入骰子名稱。
3. 使用面數旁的 `－ / ＋` 設定骰子面數，可設定 **2～20 面**。
4. 每一面都可以選擇：
   - **數字**：直接輸入數值，或使用 `－ / ＋` 調整。
   - **圖案**：切換成「圖案」後，點擊圖示欄位並從內建圖示中選擇。
5. 完成後按 **「儲存設定」**。

建立完成後，新骰子會加入下方骰子選擇列並成為目前使用的骰子。

### 3. 編輯或刪除骰子

- 點擊骰子分頁右側的編輯圖示即可開啟編輯畫面。
- 在桌面瀏覽器也可以對骰子分頁按 **滑鼠右鍵**直接編輯。
- 自訂骰子可以在編輯畫面按 **「刪除此骰子」**。
- 內建的「標準骰」不可刪除；若修改後想回復，可按 **「恢復預設」**。

### 4. 混合骰子

1. 按右上角的 **「混合骰子」**。
2. 勾選要一起使用的骰子設定；至少需要選擇 **2 種不同設定**。
3. 每種設定可指定 **1～6 顆**。
4. 按 **「開始混合擲骰」**。
5. 進入混合模式後，畫面會用不同色彩標示不同骰子設定；按 **「混合擲骰」**即可一起擲出。
6. 要回到一般模式時，按右上角的 **「離開混合」**。

混合骰子選取狀態也會暫存在目前瀏覽器中，方便下次繼續使用。

## 結果顯示

- **數字骰面**：會計算本次所有數字骰結果的總和。
- **圖案骰面**：會依圖案統計出現次數。
- 自訂骰可以同時包含數字與圖案，因此同一次結果可能同時顯示點數與圖案統計。

## 設定保存與使用限制

- 設定保存在目前瀏覽器的本機儲存空間，不需要登入。
- 本專案目前沒有帳號、伺服器資料庫或雲端同步；更換瀏覽器、裝置或清除網站資料後，既有自訂設定可能不會保留。
- 擲骰亂數目前使用瀏覽器 JavaScript 的 `Math.random()`，定位為桌遊模擬工具，沒有宣稱為密碼學、博彩或第三方公平性認證用途。
